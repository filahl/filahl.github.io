Poznámkový blok (Notepad.exe) — Přehled funkcí a zkratek

Poznámkový blok je základní textový editor určený k vytváření a úpravám prostých textových souborů s plnou podporou českých znaků a kódování UTF-8.

Klávesová zkratkaAkce
Ctrl + NNový dokument
Ctrl + OOtevřít lokální soubor
Ctrl + SUložit dokument
Ctrl + Shift + SUložit jako…
Ctrl + PTisk dokumentu
Ctrl + Z / Ctrl + YZpět / Znovu
Ctrl + X / C / VVyjmout / Kopírovat / Vložit
DelOdstranit vybraný text
Ctrl + F / F3Hledat… / Najít další
Ctrl + HNahradit…
Ctrl + GPřejít na řádek (při vypnutém zalamování)
Ctrl + AVybrat vše
F5Vložit aktuální čas a datum

Poznámka k omezením webového prohlížeče:
V prohlížečích s podporou File System Access API umožňuje příkaz Uložit přímý zápis do otevřeného souboru po udělení souhlasu. V ostatních prohlížečích funguje Uložit pomocí standardního stažení souboru.

O programu Poznámkový blok
Microsoft Windows — Poznámkový blok
Verze 10.0 (Sestavení Web Win32 Classic Recreation)

Věrná webová rekonstrukce klasické systémové aplikace notepad.exe vytvořená pomocí čistého HTML5, CSS3 a Vanilla JavaScriptu.

Plně lokální běh v prohlížeči bez externích knihoven a síťových požadavků.
